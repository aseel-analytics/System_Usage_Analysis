# System Usage Analysis

## Description
This project analyzes system usage data including user activity, login patterns, and errors.
It provides insights into system performance and user behavior.

## Dataset
The dataset contains:
- UserID
- Activity type (Login, Upload, Download, Error)
- Date
- Time

## Analysis
- Count of unique users
- User activity frequency
- Most common activities
- Errors in the system
- Activity distribution by day

## Tools Used
- Python (Pandas, Matplotlib)
- Google Colab
